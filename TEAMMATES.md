## Bằng chứng đóng góp trong Git history

Mỗi thành viên có ít nhất một commit trên branch nộp bài. Kiểm tra bằng:

```bash
git log --format="%h | %an <%ae> | %s"
```

Cột GitHub username đã được đối chiếu với GitHub API (`gh api repos/.../commits/<sha>`),
không phải suy đoán từ tên hiển thị trong `git log`.

> **Vai trò ở bảng trên suy ra từ file mà mỗi người thực sự sửa trong commit**, không
> phải do thành viên tự khai. Từng người cần xác nhận lại hoặc sửa nếu sai — một commit
> không nhất thiết phản ánh hết phần việc thật (có thể có review, thảo luận hoặc
> pair-work không để lại commit riêng).
>
> Tài khoản `mrbrownnn` xuất hiện trong `git log` là tác giả của starter repository
> gốc, **không phải thành viên nhóm**, nên không có trong bảng.
